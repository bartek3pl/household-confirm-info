Household Confirm

Household Confirm is a private automation that reads recent Netflix household update requests in the owner's Gmail account and attempts to confirm the latest request using the owner's existing Netflix browser session.

Why Gmail access is needed

The application uses the Gmail API with the gmail.readonly permission to find the request email and read its confirmation link. This permission grants read access to the mailbox. The program searches recent messages from the configured Netflix sender, verifies the exact request subject, and reads the latest matching message.

It cannot send, delete, or modify Gmail messages. There is no public signup. The owner operates the application for personal use.

How the automation runs

The program runs in the owner's AWS account. It stores the Gmail authorization in AWS Secrets Manager, browser session data in a private S3 bucket, and processing status in DynamoDB. It sends error notifications to the owner's configured email address.

This is an unofficial personal project. It is not affiliated with Netflix or Google, and its operation depends on those services.
