Household Confirm

Privacy policy

Last updated: 8 October 2026.

Household Confirm is operated by bartek3pl for personal use. This policy describes the application's use of Google user data.

Data accessed and purpose

The Gmail API permission gmail.readonly permits the application to read the authorized mailbox. The program searches recent messages from the configured Netflix sender, reads their sender, subject, timestamp and message identifier, and retrieves the latest matching household update email. It extracts the confirmation link to complete the owner's requested Netflix household update.

The application does not send, delete, or modify Gmail messages. It does not use Gmail data for advertising, sales, profiling, or training AI models.

Storage and service providers

Processing takes place locally during authorization and in the owner's AWS account during operation. The OAuth refresh token and client credentials are stored in AWS Secrets Manager. Processing identifiers and statuses are stored in DynamoDB and operational logs in CloudWatch. Complete email bodies and live confirmation links are processed in memory and are not intentionally persisted or included in application logs.

The application also stores Netflix browser session data in a private S3 bucket. Gmail authorization data and browser session data are excluded from the source repository. AWS encrypts the stored secret and session data, and access is controlled through the owner's AWS account permissions.

Google supplies the Gmail API and authorization service. AWS supplies processing, storage, logging, and email notification services. The extracted confirmation link is opened on Netflix to carry out the requested update. Google user data is not sold or shared for unrelated purposes.

Retention and deletion

Authorization and the current browser session remain stored until the owner replaces or deletes them. Processing records are configured to expire after about one day; DynamoDB expiry is asynchronous. Old browser session versions are configured for deletion after 30 days. Operational logs and delivered error notifications remain until deleted by the owner or their configured retention settings.

The owner can stop the scheduler, revoke access through Google Account permissions, and remove the secret, session data, processing records, and logs from AWS. Revoking Google access prevents further Gmail API access but does not itself delete stored AWS data.

Google API policy

Household Confirm's use of data received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
